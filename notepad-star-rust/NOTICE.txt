Notepad Star Rust - Development preview

Independent from Notepad++ and the previous C++ preview.
The folded-N/north-star logo and geometric wordmark are original Notepad Star
artwork. Source vectors, platform icons and regeneration geometry are included
in the corresponding source; no third-party font is embedded in the wordmark.
Rust owns command definitions, document state, file I/O and recovery.
Qt Widgets hosts the interface, with Scintilla/Lexilla and Boost.Regex.

This preview does not implement full Notepad++ feature parity.
Guarded file saves, recovery, sessions and selected advanced commands work.
The shared codec catalog includes 52 Unicode/legacy modes, explicit file-search
encoding, reversible code-page mappings and byte-preserving disk replacements.
Comment editing uses language/UDL markers and preserves undo/EOL state.
Preference migration previews supported XML/JSON settings and retains previous
profiles. Confirmed default restoration can repair malformed preferences.
Opt-in local instance reuse forwards bounded file/navigation requests without
overwriting open unsaved buffers. Independent windows remain the default.
Repeated macros have responsive cancellation and retain one undo group.
Document statistics and bounded locale/custom date-time insertion are available.
Editor and Document Map styles enable Scintilla's verified-monospace path.
Proportional fonts and complex text retain their original shaping behavior.
Recent/closed-file actions are wired with bounded histories and saved encoding
hints. Reopening reads disk; discarded buffer text is not retained in history.
Basic macros, settings, bounded search and local Wasm text extensions work.
Bundled language/style/completion metadata, UDL 2.1, basic project workspaces,
styled export and guarded disk replacements are implemented.
Function List, persistent tab presentation and bounded large-file viewing are
implemented. Reviewed local extension installation/update/enable/disable/removal
is available; new versions are disabled and every run requires permission.
Complete parity, an authenticated registry and application updates remain planned.
Save documents explicitly; recovery is not a replacement for backups.
